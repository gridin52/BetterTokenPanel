# BetterTokenPanel 1.0

Нативное приложение для строки меню macOS 13+. Показывает несколько независимых счётчиков, например `Claude 188.1M` и `Codex 42.0M`. Версия 1.0 включает именованные панели с отдельными интервалами обновления, локальный поиск остатка на HTTPS-страницах с подтверждением и ручным выбором числа, предупреждения о низком балансе и автозапуск при входе в macOS. Персональные ссылки и правила чтения хранятся в связке ключей macOS.

## Сборка и запуск

Нужны macOS 13+ и Apple Command Line Tools. При необходимости выполните `xcode-select --install` и дождитесь установки. Закройте старую версию через «Выйти», затем из папки проекта выполните:

```sh
bash build.sh
open dist/BetterTokenPanel.app
```

Скрипт собирает `.app` под архитектуру текущего Mac, подключает иконку и оба JavaScript-ресурса, создаёт локальную ad-hoc подпись. Это не нотарифицированный установщик для распространения. Не отключайте Gatekeeper ради запуска. Перед включением автозапуска перенесите приложение в «Программы» и запустите его оттуда.

## Автозапуск при входе в macOS

При первом запуске версии с этой функцией приложение спрашивает, включить ли автозапуск. «Не сейчас» и Escape сохраняют отказ: вопрос больше не повторяется. Выбор «Включить автозапуск» также запоминается, даже если регистрация завершилась ошибкой; повторить попытку можно в настройках. Если автозапуск уже зарегистрирован или ожидает одобрения, повторного вопроса нет.

Внизу настроек находится общий переключатель «Запускать при входе в macOS». Он действует сразу, независимо от кнопки сохранения панели, и использует системный `SMAppService.mainApp` без собственных LaunchAgent-файлов. Показания переключателя обновляются при открытии настроек и возвращении приложения на передний план. При ожидающем одобрении переключатель включён, но рядом явно указано, что запуск ещё требует разрешения macOS, и есть кнопка перехода в «Объекты входа». Автозапуск означает вход в учётную запись, а не запуск до ввода пароля.

Для этой функции требуется macOS 13+. После перемещения или пересборки приложения проверьте регистрацию заново. Добавлен тест сохранения ответа первого запуска, не изменяющий настоящие объекты входа. Компиляция Swift и фактические включение, отключение, системное одобрение и запуск после входа требуют проверки на Mac; в среде подготовки нет macOS SDK.


## Предупреждение о низком балансе

В настройках каждой панели есть поле «Предупреждать, если осталось меньше». Введите положительное целое количество токенов без сокращений: `10000000` означает 10 миллионов. Пустое поле отключает уведомления и цветовую индикацию порога. Существующие панели после обновления получают отключённый порог, остальные настройки сохраняются.

При остатке строго меньше порога число в строке меню и во всплывающем окне становится оранжевым. У самого порога предупреждения нет. Решение об уведомлении принимается только после успешного свежего чтения: сетевая ошибка или отсутствие цифр не считается нулём. Если первое успешное чтение после включения порога уже ниже него, предупреждение сработает сразу.

Уведомление отправляется один раз за серию низких показаний, а не при каждом обновлении. Состояние сохраняется между перезапусками. После успешного чтения остатка не ниже порога предупреждение снова готово к следующему снижению. Изменение самого порога или источника также сбрасывает серию. Это один запрос на показ, не гарантия доставки: Focus, настройки macOS и запрет уведомлений могут скрыть баннер. Если разрешение было запрещено, после его включения не выполняется повторная отправка той же серии; можно изменить порог или дождаться следующего перехода после восстановления баланса.

Разрешение запрашивается при первом сохранении включённого порога. Оранжевая подсветка не зависит от разрешения. При запрете или ошибке доставки в настройках появляется сообщение. Для баннеров разрешите уведомления BetterTokenPanel в системных настройках macOS. Они работают, пока приложение запущено; во время сна свежие значения не читаются.

Для логики порога добавлены Swift-проверки `Tests/low-balance.test.swift`: строгая граница, нулевой остаток, недопустимые значения, подавление повторов, восстановление, сериализация состояния. Они включены в `bash Tests/run-macos-tests.sh`, но здесь не запускались из-за отсутствия Swift/macOS SDK. Проверен синтаксис новых файлов; реальную доставку баннеров и цвета необходимо проверить на Mac.

## Исправление ручного выбора в 0.3.1

Если клик по числу раньше не срабатывал, обновите приложение до текущей сборки. Выбор теперь получает координату клика в нативном слое macOS и передаёт её в WebKit через `elementFromPoint`, а не зависит только от JavaScript-события `click`. Нативный путь предусмотрен для панелей, которые перехватывают клики или используют ссылки. Отдельно исправлен подтверждённый DOM-тестом отказ на карточке с процентом и дополнительными метриками; нативный захват клика ещё нужно проверить на Mac. Внутри WebKit добавлена более мягкая проверка ручного выбора для сложных карточек, но деньги, проценты и декоративные числовые фрагменты всё равно отклоняются.

В режиме выбора клик по числу должен сразу подсветить его синей рамкой. Если нажатие произошло, но число не подходит, справа появится причина: нажмите прямо на число, а не на подпись/процент; iframe и canvas пока не поддерживаются. Кнопка «Отменить выбор кликом» возвращает обычную работу страницы.

## Подключение и повторный выбор

В настройках добавьте панель, задайте имя, цвет и интервал, затем вставьте HTTPS-ссылку. Нажмите «Найти остаток на странице…». Можно выбрать предложенный счётчик или нажать «Указать на странице» и кликнуть по числу. Сверьте подсветку и значение, подтвердите «Да, это остаток токенов», затем нажмите «Сохранить» в настройках. Если нажать «Сохранить» с новой ссылкой без подтверждённого счётчика, сначала откроется окно выбора.

Для повторного выбора на сохранённой панели не обязательно вставлять ссылку заново: оставьте поле пустым и нажмите «Найти остаток на странице…». Ссылка будет получена из Keychain. Смена ссылки сбрасывает прежнее подтверждение. Редактирование имени, цвета и интервала не требует нового выбора.

## Безопасность сохранённого правила

Запоминается не координата на экране, а селекторы значения и подписи вместе с отпечатком структуры их локального блока. Для сложной карточки маскируются изменяемые числовые значения и соседний процент, но сохраняются подписи и порядок элементов. Если блок переставлен или изменён, чтение прекращается: автоматического переключения на другое число нет. Строгая привязка не гарантирует смысл показателя за пользователя: проверяйте, что подтверждаете именно остаток токенов, а не денежный баланс или общий лимит.

При ошибке сохраняется последнее успешное значение с `!`. Для новых универсальных правил показывается только выбранный остаток; потраченные токены и начисления не угадываются. Старые панели Freemodel продолжают пользоваться прежним адаптером до явного повторного выбора. Миграция старой одиночной ссылки в профиль «Claude» сохранена.

## Панели и интервалы


У каждой панели своё имя длиной до 16 символов, цветная метка и отдельный элемент строки меню. Название задаётся вручную: приложение не угадывает модель по API-ключу. Поддерживаются интервалы 30 секунд, 1, 2, 5, 10, 15, 30 и 60 минут. Настройки сохраняются между запусками и применяются после сохранения формы.

Во время сна Mac обновления не выполняются; после пробуждения запрашивается баланс. Параллельные загрузки одной панели не запускаются, тайм-аут чтения — 45 секунд, поэтому медленная страница может обновляться реже выбранных 30 секунд. Нулевой баланс корректен. После перезапуска старые цифры не выдаются за свежие: сначала выполняется запрос.

В настройках можно удалить панель вместе с её таймером и секретной записью Keychain, не затрагивая токены у провайдера. После удаления всех панелей в строке меню остаётся кнопка «Токены». При нехватке места macOS может скрыть счётчики, особенно рядом с вырезом экрана. Используйте короткие названия; расположение элементов можно менять, удерживая Command.

## Поддержка сайтов и ограничения

Универсальный поиск предназначен для обычных текстовых счётчиков в основном DOM страницы. Он распознаёт распространённые русские и английские подписи остатка, а ручной выбор позволяет привязаться к неизвестной статической подписи. Поддерживаются ясные форматы вроде `188.1M`, `188,1 млн`, `1 234 567`, `0` и `1.2B`. Денежные суммы, проценты, отрицательные значения и неоднозначные записи вроде `1,234` без явного множителя не принимаются. Нельзя автоматически определить, равен ли один «кредит» одному токену, поэтому такие значения не переводятся в токены.

Это не универсальный доступ к любому личному кабинету. Нужна страница, доступная по самой ссылке: cookies и входы в аккаунт не сохраняются. CAPTCHA, SSO и вход через другой домен могут не работать. Не поддерживаются счётчики в iframe, canvas, Shadow DOM, отдельный суффикс масштаба вне числового элемента, сложные неоднозначные составные блоки и очень большие DOM. Анонимный счётчик без подписи и устойчивого идентификатора может быть отклонён даже при выборе кликом. На таких страницах требуется отдельный адаптер, а не обход проверок.

Разрешены HTTPS-ссылки на домены, без логина/пароля в адресе, фрагмента `#` и нестандартного порта. Параметры запроса, в том числе персональные ключи, допускаются и считаются секретом. IP-адреса, `.local` и `.localhost` не принимаются. Навигация WebKit ограничена исходным HTTPS-origin; междоменные редиректы не разрешаются. Это не сетевой firewall и не защита от DNS rebinding: ресурсы и скрипты самой страницы могут обращаться к другим адресам, как в обычном браузере.

## Конфиденциальность

Вся персональная ссылка и DOM-правило хранятся вместе в отдельной записи связки ключей macOS для каждой панели. Даже подпись или HTML-идентификатор могут содержать чувствительные данные, поэтому отпечаток структуры не записывается в UserDefaults. В обычных настройках остаются только идентификаторы профилей, названия, цвета и интервалы. Старые строковые записи Keychain поддерживаются без обязательного повторного ввода.

Поиск выполняется локальным JavaScript в изолированном content world WebKit. Страница не отправляется нейросети, собственного сервера и аналитики нет. Это не означает отсутствие интернета: WebKit загружает панель и её обычные ресурсы у сайта. Непостоянное браузерное хранилище не создаёт постоянный профиль с cookies. Приложение не выполняет установочные команды сайта и не отправляет платные запросы к моделям.

«Открыть панель» передаёт ссылку вашему браузеру, где она может остаться в истории. Удаление `.app` не удаляет записи Keychain; для этого удалите панель в настройках. После пересборки macOS может снова запросить разрешение доступа к связке ключей.

## Проверки

Команда `node Tests/parser.test.cjs` выполняет 22 проверки прежнего адаптера без сторонних зависимостей. Новый детектор проверяется на синтетических DOM с jsdom. Чтобы запустить его, можно установить jsdom во временную папку, а не в проект:

```sh
DEPS="$(mktemp -d)"
npm install --prefix "$DEPS" jsdom@26
NODE_PATH="$DEPS/node_modules" node --test Tests/detector.test.cjs
```

В среде подготовки пройдены 32 DOM-теста нового детектора и 22 проверки прежнего парсера. Проверены автопоиск, несколько кандидатов, нулевой баланс, локальные числовые форматы, выбор кликом, блокировка обычных кликов в режиме выбора, восстановление подсветки, чтение сохранённого правила после перезагрузки, отказ при перестановке блоков, смене подписи, деньгах и процентах. DOM-тесты не заменяют реальный WebKit.

Для macOS предусмотрен `bash Tests/run-macos-tests.sh`: проверки модели, интервалов, сохранения профилей, URL и origin-ограничений, сериализации правила. Они не обращаются к настоящим секретам. Эти macOS-проверки, компиляция Swift, внешний вид окон, реальный Keychain и интеграция с живыми панелями здесь не запускались: в доступной среде нет macOS SDK. Синтаксический разбор Swift и проверка shell-скриптов выполнены, но не заменяют сборку.

Перед использованием проверьте на Mac подключение двух панелей, сравнение с сайтом, перезапуск приложения, ручной выбор, смену ссылки, обновление после изменения структуры страницы и ошибку при отключённом интернете. Иконка приложения сохранена: векторный исходник, PNG и ICNS находятся в `Assets`.
